# 업로드 문구 규칙 — 제목·설명·해시태그·태그·클립 설명 (Claude Code가 쓴다)

2026-10-11 변경: **업로드에 쓰이는 문구는 전부 Claude Code가 `upload.json`에 최종본으로 적는다.** Aside는 그것을 **한 글자도 고치지 않고 그대로 입력**하는 일(업로드·예약·기록)만 한다. 예전에는 `upload.json`에 설명 본문만 쓰고 해시태그·설치 안내·최종 제목은 Aside가 정했다.

이 파일은 그 문구를 쓸 때의 규칙이다. 원본은 Aside 스킬의 `references/keywords-hashtags.md` 3·5절, `youtube-publish.md` 6절, `writing-common.md` 4·8·9항이었고, 이쪽으로 **옮겼다**(Aside 쪽 해당 부분에는 "대체됨" 표시가 있다). 두 곳을 같이 고치지 않는다 — **고칠 곳은 여기뿐이다.**

## 1. upload.json 항목에 적는 필드

`"편id/언어"` 키 아래, 기존 필드(`id` `lang` `file` `thumbnail` `category` `category_name` `made_for_kids` `default_language` `rendered_at` `youtube_id` `links` `uploaded_at`)에 더해:

| 필드 | 값 |
|---|---|
| `title` | **최종 유튜브 제목**(임시 제목 아님). 100자 이내 |
| `description` | **최종 유튜브 설명 전체** = 한 줄 본문 + 빈 줄 + 해시태그 한 줄 + 빈 줄 + 고정 장점 블록 + 빈 줄 + 고정 설치 안내 블록 |
| `hashtags` | 설명에 넣은 해시태그 목록(`["#…", …]`, 참고·검증용) |
| `tags` | 유튜브 **태그 칸** 값(`#` 없이). 해시태그와 같은 단어 |
| `naver_caption` | **네이버 클립 설명 전체**(300자 이내, 한국어판만). 형식은 4절 |
| `metadata_final` | `true`일 때만 Aside가 업로드한다. 사용자가 이 문구를 승인한 뒤에만 `true`로 바꾼다 |
| `finalized_at` | 승인 날짜 `YYYY-MM-DD` |

- 승인 전 초안은 `metadata_final: false`로 둔다. Aside는 `false`이거나 필드가 없는 항목을 **업로드하지 않고 멈춘다.**
- 승인 후 문구를 한 글자라도 고치면 `metadata_final`을 `false`로 되돌리고 다시 승인받는다.
- 2026-10-11 이전에 만든 항목은 예전 형식이다(`metadata_final` 없음). 올리기 전에 이 규칙대로 다시 써서 승인받는다.
- `publish.json`에는 Aside가 실제로 입력한 값을 `title_live`·`description_live`·`caption_live`·`tags_live`·`hashtags_live`로 적는다. 승인본과 다르면 안 된다 — 검증 때 대조한다.

## 2. 설명 최종 형태 (2026-10-11 사용자 결정: 설명 최소화 + 고정 장점 블록)

영상·썸네일의 내용을 설명에 풀어 쓰지 않는다. 본문은 **검색어를 담은 한 줄**이면 충분하다.

```
{본문 — 한 줄}

{해시태그 한 줄}

{고정 장점 블록}

{고정 설치 안내 블록}
```

### 고정 장점 블록 (모든 영상·모든 언어에 항상, 설치 안내 바로 앞)
한국어 원문 — 그대로 쓴다(글자 수 때문에 클립 설명에도 같은 문구를 쓴다):
```
안부의 특징
- 배터리 사용을 최소한으로
- 안드로이드·아이폰 모두 지원
- 20개 언어 지원: 한국어, 영어, 일본어, 중국어(간체), 중국어(번체), 독일어, 프랑스어, 스페인어, 이탈리아어, 네덜란드어, 포르투갈어, 러시아어, 아랍어, 튀르키예어, 폴란드어, 베트남어, 태국어, 스웨덴어, 힌디어, 인도네시아어
```
- "20개 언어"다(20개국이 아니다 — 중국어 간체·번체, 포르투갈어(브라질)처럼 나라와 1:1이 아님). 언어 이름은 앱 번역 파일 20개(ko_KR … id_ID)와 같아야 한다 — 언어를 추가·삭제하면 이 블록을 고친다.
- 다른 언어판은 **현지어로 같은 3줄**을 쓰고(제목 "안부의 특징"→ 그 언어의 "Anbu의 특징" 식으로, 앱 이름은 `Anbu`), 20개 언어 이름도 **그 언어로** 나열한다. 번역은 `.claude/translation_glossary.md`를 먼저 읽는다.
- ⚠️ **"배터리 사용을 최소한으로"는 설계 방침이지 측정값이 아니다**(PRD-FrontEnd §1.3 "최소 배터리 소모", 성공 지표 "하루 1% 미만 추가 소모"는 목표). 수치·"거의 안 쓴다" 같은 단정으로 바꾸지 않는다.
- ⚠️ **"안드로이드·아이폰 모두 지원"에 "아이폰은 보호자 전용" 같은 내부 구분을 쓰지 않는다**(아이폰도 G+S로 안부를 보낼 수 있다 — 사용자용 문구로 옮기면 거짓 정보가 된다).
- 네이버 클립 설명(300자)에도 같은 블록을 넣는다. 클립은 본문 한 줄을 생략하고(첫 줄 = 제목) 글자 수를 맞춘다.

### 고정 설치 안내 블록
- **한국어 문구 그대로**(2026-10-01 확정):
  ```
  자세한 설명 및 다운로드는
  https://averic.co.kr
  스토어에서 'Anbu'를 검색해 주세요.
  ```
  다른 언어는 현지어로 같은 순서(`averic.co.kr` 먼저, 그다음 스토어에서 `Anbu` 검색). 스토어 검색어는 모든 언어에서 `Anbu`.
- 링크 뒤에 한글을 바로 붙이지 않는다(`averic.co.kr에도` ✗). 스토어 직링크는 넣지 않는다. `averic.co.kr` 하위 경로를 붙이지 않는다.
- 쇼츠 설명의 URL은 클릭되지 않는다(유튜브 정책). 텍스트 안내로만 기능한다.

### 본문
- 시청자에게 말한다. 제작 메모 어투("~하는 영상입니다", "마지막 문구:")를 쓰지 않는다. 영상 엔딩 문장·스토어 안내를 본문에서 반복하지 않는다.
- 앱 이름: 한국어만 `안부`, 나머지 19개 언어는 `Anbu`. 일본어판 제목·설명·태그에는 `安否確認`을 키워드로 넣는다(브랜드명으로는 쓰지 않음).

## 3. 해시태그

### 한국어
- **고정**: `#1인가구 #부모님안부 #안부확인` — 순서 고정, `#1인가구`가 맨 앞.
  - 2026-10-11 Aside 조사(네이버·유튜브·틱톡)로 `#혼자사는사람`이 틱톡에서 만남·스팸 피드와 섞이고 유튜브·네이버에서도 영화·예능 노이즈라 제외 후보가 됐다. **고정 태그 변경은 사용자 승인 사항이다.** **승인 기록: 2026-10-11 사용자 승인 — 고정 `#1인가구 #부모님안부 #안부확인`(`#혼자사는사람` 제외).** 편별 추가는 그 편에 맞게 1~2개(이 편은 `#출국준비 #여행필수앱`).

- **추가 1~2개**: 그 편에만 맞는 것. 아래 「좋은 키워드」에서 고르고, 새 단어는 자동완성으로 수요를 먼저 확인한다.

## 4. 제목과 네이버 클립 설명

- **제목**: 그 편의 검색어를 자연스러운 말로 넣는다. 제목·첫 줄이 해시태그보다 검색 순위를 먼저 정한다.
- **네이버 클립**은 제목 칸이 없다 → 설명 **첫 줄에 유튜브 제목과 같은 문장**, 빈 줄, **고정 장점 블록**, 빈 줄, 설치 안내 블록, **해시태그는 맨 끝**(본문 한 줄은 300자 때문에 생략).
  ```
  {유튜브 title과 같은 문장}

  {고정 장점 블록}

  {고정 설치 안내 블록}
  {해시태그}
  ```
- 길이는 **글자 수를 직접 센다**(공백·줄바꿈 포함).
- 네이버 클립은 한국어판만 올린다(다국어는 유튜브만).

## 5. 쓰면 안 되는 표현 · 앱 사실 검사 (공개 문구라 거짓이면 광고가 거짓이 된다)

`shorts` 스킬 1절 「앱 사실 검사」 표를 설명에도 그대로 적용한다. 요점:
- 안부는 **연결된 보호자에게만** 간다(코드를 주고받아야 연결됨). **하루 한 번 자동** 전송(전화·앱 실행 불필요). **정시·"매일 예약 시각에 도착"을 약속하지 않는다** → "하루 한 번".
- 응급 구조 앱이 아니다. 긴급 도움 요청은 **필요할 때만 쓰는 기능**이고 119·구조를 약속하지 않는다. 위치는 그때 1회만 쓰고 당일 자정에 지워진다.
- 안부는 전화·명절 인사를 **대신하지 않는다**.
- **시간대**: 안부 시각은 "현재 있는 곳의 현지 시각"이고 시간대는 안부를 보낼 때 자동으로 맞춰진다(PRD-FrontEnd §2.2.3). "도착하면 앱을 열어 시각을 맞춰야 한다"고 쓰지 않는다. 앱을 열면 바로 맞춰진다는 정도까지만.
- 요금은 "3개월 무료 체험, 이후 연 $9.99"를 함께 쓴다(요금을 언급할 때). `#무료앱` 계열은 금지.
- ~~공포 마케팅(고독사 통계를 자극적으로)~~(2026-10-11 폐기: 심사·플랫폼 정책 범위 안에서는 자극적 표현도 쓴다. 단 통계는 출처가 있는 사실만, 거짓·과장된 약속은 금지), 죄책감 자극("연락 안 하는 당신"), 과장("완벽하게", "100%", "절대"), 감시 연상, 제조사 실명(삼성·샤오미 등), 특정 제품명·가격 추천, 기술적 해결 방법의 구체적 서술, 직접 측정한 수치의 단정형 서술, 사업자 개인정보를 쓰지 않는다. 메시지는 "연락을 더 하자"가 아니라 **"연락을 못 해도 되게 만든다"**.
- 제품의 한계: 폰 전원이 완전히 꺼지면 안부가 전해지지 않는다. "멈추지 않아요" 같은 단정에는 이 예외를 작게 병기한다.
- 응급 구조·위치 추적·감시를 **약속하는** 표현 금지.

## 6. 승인 절차

1. 제목·설명·해시태그·태그·클립 설명을 한 번에 채팅에 보여 준다(글자 수 포함).
2. 사용자가 승인하면 `metadata_final: true`, `finalized_at`을 적는다.
3. 한국어를 먼저 승인받는다. 다국어는 한국어 승인본을 기준으로 현지화하고, **다국어도 올리기 전에 초안을 보여 준다**(예전에는 Aside가 알아서 올렸으나 이제는 아니다).

## 7. 공개 정책 · 캘린더 (2026-10-11 사용자 결정)

- **새로 제작된 영상은 썸네일이 들어간 채로 업로드가 끝나면 바로 공개한다**(예약 슬롯을 잡지 않는다). 유튜브는 공개 상태 "공개", 네이버 클립은 "등록 예약"을 켜지 않고 바로 등록한다.
- 썸네일(jpg)이 없는 영상은 올리지 않는다(공개가 아니라 **업로드 자체를 보류**하고 사용자에게 알린다).
- **구글 캘린더 일정은 등록하지 않는다**(바로 공개되면 챙길 예약이 없다). 예약 공개를 일부러 걸 때만 등록한다.
- 이 정책은 이 날짜 이후 새로 만든 영상에 적용한다. 이미 올라가 있는 예전 영상은 바꾸지 않는다. 다국어판에도 같은 정책이 적용되는지는 처음 다국어를 올릴 때 사용자에게 한 번 확인한다(한 채널에 여러 언어를 한꺼번에 공개하면 시청자 신호가 흐려진다는 예전 판단이 있었다).
- 공개는 **되돌리기 어렵다**: 문구 승인(`metadata_final: true`) 없이는 공개하지 않는다.

## 8. 노출 우선 정책 (2026-10-11 사용자 결정)

- 앱 노출이 우선이다. 검색되는 단어가 불쾌·공포감을 주는 표현이어도 **스토어·플랫폼 심사 정책 범위 안에서는 쓴다.** 막히는 선·공식 문서 근거·허용/금지 목록은 앱 저장소 `CLAUDE.md` 「노출 우선 문구 정책」이 원본이다(여기에 옮겨 적지 않는다).
- 쇼츠 해시태그·제목·설명에서의 의미: `#고독사`·`#고독사예방`·`독거노인`을 쓸 수 있다. 단, 다른 앱 이름(`죽었니`·`死了么`·`Are You Dead`)을 해시태그·제목에 넣지 않고, "고독사를 막아 준다" 같은 **사실과 다른 약속**은 쓰지 않는다(앱 사실 검사 §5).
